# APD – Laborator
Proiect de laborator pentru disciplina Achiziția și prelucrarea datelor.
Nod de achiziție a temperaturii bazat pe Arduino Uno.

## Autor
PAGU ADRIAN GR 2 B

## Hardware
Arduino Uno R3, senzor de
temperatură TMP36

## Parametri
- `SENSOR_PIN` – intrarea analogică a senzorului (A0)
- `SAMPLE_PERIOD_MS` – perioada de eșantionare, în ms
- `SERIAL_BAUD` – viteza portului serial
- `LED_PIN` – LED de stare (pin 13)
- `BUTTON_PIN` – buton de pornire/oprire achiziție (pin 2)Comunicație serială la 19200 baud
